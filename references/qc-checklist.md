# QC チェックリスト

各項を PASS / FAIL で判定し、FAIL には**どの行が違反か**を引用して返す。
1件でも A 群に FAIL があれば全体 FAIL。B 群は2件以上の FAIL で全体 FAIL。

## A群（1件でも落ちたら差し戻し）

### A1. 構造
- 10段が順番通りに揃っているか。欠けている段はどれか。
- Identification Hook に**商品名・成分名・約束・「〜でお悩みの方へ」型の呼びかけ**が入っていないか。
- Soft CTA が「買え」と言っていないか。命令形の購入喚起があれば FAIL。

### A2. 法務（日本・健康系）
- **効能効果の断定**がないか（治る・改善する・治癒・完治・効果がある）。
- **医薬品的な機序の断定**がないか（神経を修復する・血流を治す・炎症を消す）。
- **ビフォーアフターの数値**を商品の効果として提示していないか。体験の記述と効果の証明を混ぜない。
- 医師・医療機関の推薦を装っていないか。実在の研究を出す場合、出典が実在し内容が一致しているか。
- 競合の実名を挙げて貶していないか。

### A3. 出典の実在
- 引用した研究・論文・地名・団体が**実在するか**。捏造なら FAIL。
- VoC の言葉として使ったフレーズが `voice-research-*.md` の言語バンクに実在するか。

## B群（2件以上で差し戻し）

### B1. 声
- 書き手の語彙に翻訳していないか。言語バンクの言葉をそのまま使っているか。
- 日本語として不自然な直訳（「〜な瞬間」「〜というもの」の多用、無生物主語）がないか。
- 一人称の語りとして一貫しているか。途中で広告主の声に戻っていないか。

### B2. 心理設計
- Problem Mechanism が「**なぜ今まで試したものが効かなかったか**」を説明しているか。
- その説明が「効かなかった」の5類型のどれに当たるか明示できるか。
  （効き足りない／副作用との取引／一時的／機序がずれている／試すこと自体に疲れた）
- Solution Mechanism が「**今回は違う論理的な理由**」を与えているか。
- Transformation の初期に**変化がない期間**があるか（いきなり効くと嘘くさい）。
- Rock Bottom に**具体的な数字か場面**があるか（金額・時刻・誰がいたか）。
- Identity Shift が症状の話でなく**生活・関係・自己像**の話になっているか。

### B3. 日本市場への適合
- 医者不信・反製薬の論調が強すぎないか。米国原典のまま持ってきていないか。
- 「言われた通りやったのに」の肯定が入っているか（怠慢を責める構図になっていないか）。
- 家族・配偶者の一言が入っているか。日本では他人の評価より近しい人の言葉が効く。

## 出力形式

```
判定: PASS / FAIL
A群: A1 PASS / A2 FAIL（該当行: "..."）/ A3 PASS
B群: B1 PASS / B2 FAIL x1（該当: ...）/ B3 PASS
差し戻し理由: （FAILのみ簡潔に）
```

修正案は書かない。書き手に戻す。
